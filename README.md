# fms_eeg_hyperscanning

adapting foundation models for hyperscanning eeg datasets

│   └── workflows/
│       └── tests.yaml
├── configs/                  # Configuration files
├── data/                     # Data directory
│   ├── processed
│   └── raw
├── dockerfiles/              # Dockerfiles
│   ├── api.Dockerfile
│   └── train.Dockerfile
├── docs/                     # Documentation
│   ├── mkdocs.yml
│   └── source/
│       └── index.md
├── models/                   # Trained models
├── notebooks/                # Jupyter notebooks
├── reports/                  # Reports

│   ├── project_name/
│   │   ├── __init__.py
│   │   ├── api.py
│   │   ├── data.py

Created using [mlops_template](https://github.com/SkafteNicki/mlops_template),
a [cookiecutter template](https://github.com/cookiecutter/cookiecutter) for getting
started with Machine Learning Operations (MLOps).

## Braindecode EEG classification

The production pipeline is documented in [src/labram_classification/README.md](src/labram_classification/README.md).
It supports MirrorGame's three pairwise contrasts, ForceGame feedback classification, and Circling,
with grouped ten-fold evaluation and an offline HPC job template. The earlier tutorial scripts are
preserved separately in [src/labram_classification_lessons/](src/labram_classification_lessons/).
